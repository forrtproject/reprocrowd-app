To reproduce the results from the manuscript use the R-script in this folder: https://osf.io/2m3w6

The r-script will automatically download the raw dataset (https://osf.io/2s3tv), process it, and generate the results.

To run further analyses with the processed data, use the most recent processed dataset: https://osf.io/bkgdh
The central variables are in the dataset's last columns.


CENTRAL VARIABLES
name		description
ai		affect index
nfc		need for cognition
expectation	expectation condition
nfc_pos		whether nfc was measured before or after watching the movie
ac1		attention check question 1 (TRUE = correct)
ac2-ac4		see ac1
ac		number of correct attention check items
