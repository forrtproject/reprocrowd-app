- With 25 trials, only 0 hits would reject downward (one-sided P(X <= 0) = 0.0105); 1 hit already gives P(X <= 1) = 0.0629. Ada's 3 hits are far from that boundary.

- Beyond sample size, a below-chance claim would need a mechanism that survives trial-by-trial feedback: systematically swapped flavor labels should be visible as stable off-diagonal structure in the confusion matrix (see 1.3) and should erode with feedback if labels are relearnable. Neither a stable swap pattern nor 0 hits is present, so the paper reports Ada as indistinguishable from guessing.

## 2. Learning check [fn section2, fn stratified_trend]

Question: did immediate feedback produce accuracy gains across the 25 trials? Decided before the later analyses because a positive answer would force a trial-order covariate into all of them.

Design of the primary test. A raw accuracy-on-time correlation is confounded: later trials can contain easier flavor mixes, and flavors differ in identifiability. The test therefore stratifies by person x flavor cell: within each cell, the k-th exposure to a flavor is compared with earlier exposures of the same flavor by the same person, which is exactly what feedback could have taught (`prior_own_exposures_flavor`; the within-cell exposure rank is that count plus one). Statistic: T = sum of within-cell-centered exposure rank x outcome; null: outcomes shuffled within cell (10,000 draws). `feedback_prior_own` enters the same stratified scheme as a global-time index (spacing information); `feedback_prior_observed` is a perfect linear function of `feedback_prior_own` within person (codebook collinearity warning) and is therefore not tested separately.

|---|---|---|---|
| accuracy on flavor-specific exposure count (primary) | 2.00 | 0.036 | p = 0.8256 |
| accuracy on global trial position (same stratified null) | 6.12 | 0.025 | p = 0.8054 |
| certainty on global trial position | -131.27 | -0.176 | p = 0.1250 |
| certainty on flavor-specific exposure count | -15.00 | -0.088 | p = 0.4533 |

## 4. Awareness of one's own flavor preferences [fn section4, fn rel_effects_weighted_tasted]

Do people know which flavors they uniquely like? Social-relations logic: relationship effects (cell - perceiver mean - target mean + grand mean) computed separately for the a priori liking ratings (`apriori_like`) and the tasted-bear liking cell means (`mean_liking_tasted`), then correlated across the 24 person x flavor cells. Removing the margins is what makes this awareness of *unique* preferences: perceiver-level response tendencies and flavor-level consensus are taken out. Permutation test: each person's six a priori ratings shuffled within person (margins re-derived each draw), 10,000 draws, two-sided; this preserves each person's rating distribution and breaks only the flavor correspondence.

Cell sizes run 1 to 8 (Ada tasted lemon once), so the 24 tasted cell means differ widely in precision (codebook precision warning). Both requested variants are run: unweighted (equal cell weight, margins from cell means) and weighted (trial-based margins, correlation weighted by cell n).

| Variant | r (a priori rel x tasted rel) | Permutation p |
|---|---|---|
| unweighted (24 cells) | 0.310 | p = 0.2150 |
| weighted by cell n (trial-based margins) | 0.331 | p = 0.1284 |
| unweighted, single-trial cell (Ada x lemon) dropped, 23 cells | 0.299 | p = 0.2390 |
| Spearman on unweighted relationship effects | 0.310 | (descriptive robustness) |

The 24 correlated values are not independent (each person contributes six double-centered cells, each flavor four); the permutation test is built on the actual exchangeability structure and is the inference to trust, not an off-the-shelf p for r with df = 22.
For reference, that off-the-shelf test on the unweighted r = 0.310 (t = r sqrt(22) / sqrt(1 - r^2) = 1.530, df = 22, two-sided) would report p = 0.140; the manuscript quotes this only as the conventional-test contrast to the permutation p above.
